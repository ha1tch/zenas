# golden_vectors.txt - verified mnemonic/bytes pairs, as plain data.
#
# Format: one instruction per line, "SOURCE|HEXBYTES". SOURCE is exact
# zenas assembly syntax; HEXBYTES is the uppercase hex encoding, no
# separators. Lines starting with # are comments.
#
# Intended for a downstream fork's own encoder to verify against
# directly, without hand-transcribing bytes from release notes or
# needing to build zenas itself. Regenerate with:
#   ZENAS=./build/zenas tools/gen_golden_vectors.sh > tools/golden_vectors.txt
#
# Source of truth: the documented-instruction-set lines (from
# instr_coverage_list.txt) are zenas's own assembled output for forms
# already cross-checked against pasmo as part of this project's own
# release process (see check_instr_coverage.sh) -- this file doesn't
# re-run that cross-check, it exports the already-trusted result. The
# undocumented-instruction lines at the end can't be cross-checked
# against pasmo at all (it doesn't recognise them); those were
# verified instead against multiple independent Z80 documentation
# sources during development -- see CHANGELOG.md's [0.9.0] entry.
